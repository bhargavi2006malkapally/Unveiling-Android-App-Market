# Unveiling-Android-App-Market
Android App Market Analysis Dashboard using Python, Pandas, Matplotlib and Streamlit

Project Overview

Unveiling the Android App Market is a data analytics project that explores trends and insights from the Google Play Store dataset. The project analyzes app categories, ratings, reviews, installs, and app types to understand patterns in the Android app ecosystem.

Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit

Features

- Top App Categories Analysis
- Top Rated Categories Analysis
- Most Installed Apps Analysis
- Rating Distribution Analysis
- Free vs Paid Apps Comparison
- Reviews vs Ratings Correlation
- Interactive Category Filter
- Interactive App Type Filter

Key Insights

- The majority of apps on the Play Store are free.
- Communication and Social categories show high average installs.
- Categories such as Events and Education have high average ratings.
- Apps with more reviews generally tend to have higher visibility and installs.

Dashboard

The project includes an interactive Streamlit dashboard that allows users to explore app market trends through visualizations and filters.
